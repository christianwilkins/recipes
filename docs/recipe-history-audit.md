With JavaScript, only the selected panel is visible; without JavaScript, every documented variant remains readable. Grocery additions and copied/shared prompts use the selected variant. Print CSS prints the selected panel and hides controls, history-gap disclosures and agent prompts.

Agent prompt controls previously appeared before all ingredients, pushing cooking content down the page. They now follow the recipe. Existing skip link, focus outlines, 44px button heights, status regions, responsive one-column reading and grocery controls are preserved.

No serving-scaling control existed in the inspected baseline. This branch preserves exact documented batch sizes rather than introducing an unverified quantity parser.
